# RedFish - Miroir Web

Prototype visuel rapide (React via CDN) pour voir les ecrans principaux sans Mac/Xcode.

## Ouvrir

- Double-clique sur `index.html`, ou
- Lance un serveur statique local et ouvre `http://localhost:.../web-mirror/index.html`.

## Ce que ce miroir montre

- Onglets `Camera`, `Galerie`, `Fil`
- Compteur de pellicule (30 vues)
- Bouton capture mock
- Passage en mode developpement quand la pellicule est pleine
- Modal "developpement" puis affichage en galerie/fil

## Limites

- Pas de logique iOS native (camera, SwiftData, permissions, stockage reel)
- But: valider look & navigation uniquement
